
# Odin-Markdown

Terminal-first viewer for Markdown files. Odin uses OpenTUI.

<img width="1240" height="997" alt="screenshot-20260611-055813Z-selected" src="https://github.com/user-attachments/assets/330484ef-e393-41e2-abb3-46f91d0cf365" />

## Install

```bash
npm install -g odin-md
```

## Usage

```bash
odin file.md
```

## Development

```bash
bun install
bun run build
bun run dev <Markdown-file-name>.md
```
